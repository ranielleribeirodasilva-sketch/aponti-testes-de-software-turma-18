# Aulas de GIT e GITHUB

> Aprender Git e GitHub é transformar linhas de código em pontes para o futuro do desenvolvimento.

---

## 🎯 Objetivo

O GitHub funciona como o "LinkedIn dos programadores". Aprender a usá-lo serve para mostrar ao mercado e aos recrutadores o seu código, sua evolução e como você colabora com outros projetos.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas e tecnologias:

* **[VS Code]**  - Possui uma das melhores e mais populares integrações com Git e GitHub.

---

📁 Estrutura das Pastas

Abaixo está a representação da estrutura de diretórios do projeto:
meu-projeto/
├── src/
│   ├── assets/          # Imagens, fontes e arquivos estáticos
│   ├── components/      # Componentes reutilizáveis da interface
│   ├── services/        # Integrações com APIs e serviços externos
│   ├── views/           # Páginas principais do aplicativo
│   ├── index.js         # Ponto de entrada da aplicação
│   └── routes.js        # Configuração de rotas
├── .gitignore           # Arquivos ignorados pelo Git
├── README.md            # Documentação do projeto
└── package.json         # Dependências e scripts do projeto



## 🚀 Como Executar o Projeto

Siga os passos abaixo para configurar e rodar o projeto localmente na sua máquina.

### 📋 Pré-requisitos

Antes de começar, você precisará ter instalado em seu computador as seguintes ferramentas:
* **Git:** Para clonar o projeto ([Baixar Git](https://git-scm.com/)).
* **Node.js:** (Versão 18 ou superior) Para executar o ambiente JavaScript ([Baixar Node.js](https://nodejs.org/)).
* Um editor de código de sua preferência (recomendamos o **VS Code**).

---

### 🛠️ Passo a Passo

Abra o terminal do seu computador (ou o terminal do VS Code) e execute os seguintes comandos, um por um:

#### 1. Clonar o Repositório
Copie o projeto do GitHub para a sua máquina local executando o comando abaixo:

git clone https://github.com/ranielleribeirodasilva-sketch/seu-repositorio.git
